## What I build

I design software where reliability matters more than novelty.

My work focuses on **human-in-the-loop automation**, **AI workflow execution**, **Apple platforms**, **smart-home systems**, and tools that make complicated systems easier to understand and control.

```text
powerful automation
        +
explicit permissions
        +
verifiable outcomes
        +
recoverable failures
        =
software people can trust
```

## Engineering perspective

> Software should be observable, constrained, and recoverable before it is called intelligent.

- Build around real workflows, not decorative AI wrappers.
- Make permissions and trust boundaries explicit.
- Verify outcomes instead of assuming success.
- Design failure states as carefully as happy paths.
- Use interfaces to make complex systems understandable.
